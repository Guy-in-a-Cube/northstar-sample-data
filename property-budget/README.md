# Property Budget

Property Budget represents planned property budgets. Its business identity is independent of where the data is stored. In Fabric Explained, the source system is a SharePoint list owned by the learner.

## Included Files and Evidence

Only this guide is included. The seed CSV and SharePoint column definitions were not supplied. No actual filename, columns, budget period, currency, row grain, property identifier, keys, row count, or date coverage is verified. Do not assume one row per property or a particular relationship to the operational exports. See [schema evidence](../schema/README.md).

## General Source Setup

Once approved source files are available:

1. Use the Property Budget seed CSV from the same dataset release as your other files.
2. Create your own SharePoint list using the verified column definitions. Seed the list from the CSV using a supported list-import workflow in your environment; review the mapping and inferred column types before accepting them. Exact UI steps and CSV import availability have not been verified here.
3. Preserve source identifiers separately from any item IDs generated by SharePoint. Do not assume generated list IDs are operational property identifiers. Confirm mappings against the supplied dictionary rather than inventing a join.
4. Check list item counts against the parsed CSV count and inspect representative values, blank/null behavior, date interpretation, and numeric precision. Check that the account intended for downstream access can read the list.

The list, not the original CSV, becomes the active source system. Reimporting the seed may duplicate items; choose a controlled reset or update strategy in your own list.

## Fabric Explained Only

The course mirrors the learner's **SharePoint list into Fabric**. It does not mirror the CSV. Loading the CSV directly into Fabric is a different exercise and does not establish SharePoint mirroring.

Microsoft's tutorial requires an active Fabric subscription and a workspace with an appropriate Trial or Premium Fabric capacity. After preparing your list, follow the current tutorial to create a Mirrored SharePoint Online List connection using your own site and authorized credentials, select the intended data, and monitor replication. Readiness means the intended list is selected, replication status is healthy, and the mirrored data is queryable with expected values after the initial synchronization. Account for synchronization delay before comparing counts.

No mirroring configuration is included or performed. Tenant feature availability, access permissions, supported list column types, and your list's compatibility require verification in your environment. The referenced overview and tutorial do not establish a complete supported-type matrix or a guaranteed replication latency for this dataset. Do not substitute a document-library shortcut for list mirroring.
